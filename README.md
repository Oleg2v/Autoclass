# Auto Class — демо главной страницы

Демо одностраничного сайта для **אוטו קלאס – מרכז שירות לרכב** (кузовной ремонт и покраска, הסולל 3, Холон, с 1960 года).
Клиент — **autoclassltd.com** (не путать с autoclass.co.il — другая компания из Явне).

- Живое демо: **https://autoclass.kikkey.com** (зеркало на Cloudflare Pages: https://autoclass-kikkey.pages.dev)
- Концепция и референсы: [`docs/DESIGN.md`](docs/DESIGN.md)
- Все тексты на иврите с русским переводом: [`docs/copy-ru-he.md`](docs/copy-ru-he.md)
- Режим комментариев: [`docs/COMMENTS.md`](docs/COMMENTS.md)
- Отчёт Lighthouse и скриншоты: [`docs/report/`](docs/report/)

---

## Запуск

```bash
npm install
npm run dev          # http://localhost:4321
npm run build        # статическая сборка в dist/
npm run preview      # локальный просмотр сборки
```

Вспомогательные команды:

```bash
npm run copy-doc     # пересобрать docs/copy-ru-he.md из src/data/copy.js
npm run fonts        # пересобрать сабсеты шрифтов (нужны python3 + pip install fonttools brotli)
```

Стек: Astro 7 (static), vanilla JS, GSAP 3 + ScrollTrigger, Lenis (только десктоп), self-hosted Noto Sans Hebrew (variable, оси wght/wdth) и Frank Ruhl Libre.

### Где что лежит

| Путь | Что это |
|---|---|
| `src/data/site.js` | **факты**: телефон, адрес, e-mail, часы, рейтинг и отзывы Google — единый источник |
| `src/data/copy.js` | **все тексты** на иврите + русский перевод рядом |
| `src/components/car/` | SVG-машина (собственная обобщённая иллюстрация, без марки) и её геометрия «помятая/восстановленная» |
| `src/components/*.astro` | секции страницы |
| `src/scripts/` | анимации и интерактив (прогрессивное улучшение: без JS страница полная) |
| `src/assets/photos/` | реальные фото с autoclassltd.com (оптимизируются в AVIF/WebP при сборке) |
| `workers/comments/` | Worker + Durable Object (SQLite) для комментариев |
| `workers/site/` | Worker сайта на autoclass.kikkey.com: статические файлы + прокси `/api/comments/*` |
| `functions/api/comments/` | Pages Function для зеркала на Pages: прокси `/api/comments/*` → Worker |
| `public/review/` | виджет комментариев (грузится только по ссылке ревью) |

## Деплой (Cloudflare)

Боевой адрес **https://autoclass.kikkey.com** обслуживает Worker `autoclass` (Workers Static Assets: файлы из `dist/`, учитываются `dist/_headers` и `dist/404.html`) с custom domain — так же, как остальные демо на `*.kikkey.com`. Запросы `/api/comments/*` он передаёт в Worker `autoclass-comments` (Durable Object + SQLite).
Почему не Pages-домен: у API-токена нет прав на DNS, поэтому Pages не может получить CNAME; Workers Custom Domain создаёт DNS-запись и сертификат сам. Pages-проект `autoclass-kikkey` оставлен зеркалом: https://autoclass-kikkey.pages.dev (те же файлы, `/functions` проксирует тот же API).

```bash
# 1. API комментариев (при изменениях в workers/comments)
cd workers/comments && npx wrangler deploy
npx wrangler secret put REVIEW_KEY      # ключ из ссылки ревью
npx wrangler secret put NTFY_TOPIC      # секретное имя темы ntfy (пуш-уведомления)
npx wrangler secret put NOTIFY_EMAIL    # адрес для писем (работает вместе с NTFY_TOKEN)
npx wrangler secret put NTFY_TOKEN      # токен бесплатного аккаунта ntfy.sh — нужен для писем
# 2. Сайт
cd ../.. && npm run build && cd workers/site && npx wrangler deploy
# 3. (необязательно) зеркало на Pages
cd ../.. && npx wrangler pages deploy dist --project-name autoclass-kikkey --branch main
```

Секретов в репозитории нет: ключ ревью, тема ntfy, e-mail и токены хранятся как secrets Worker'а.

### Уведомления о новых комментариях
- **Пуш (работает сейчас):** установите приложение ntfy (iOS/Android) или откройте https://ntfy.sh/app и подпишитесь на тему из секрета `NTFY_TOPIC`. Каждое новое сообщение/ответ приходит с текстом и ссылкой, открывающей страницу сразу на нужном пине.
- **Письмо на e-mail:** ntfy.sh с 2025 года не пересылает письма анонимно (проверено 23.11.2026, ошибка 40053). Нужно один раз завести бесплатный аккаунт на ntfy.sh, создать access token и положить его в секрет `NTFY_TOKEN` — адрес `NOTIFY_EMAIL` уже задан. Пока токена нет, Worker автоматически шлёт пуш без письма.
- **Альтернатива:** Telegram-бот — секрет `WEBHOOK_URL` = `https://api.telegram.org/bot<token>/sendMessage?chat_id=<id>`.

## Что должен подтвердить владелец

Всё ниже взято с autoclassltd.com или из Google-профиля «מוסך אוטו קלאס חולון» (проверено 23.11.2026), но требует подтверждения. В режиме ревью (`?review=…`) спорные блоки на странице обведены красным пунктиром с плашкой «לאישור הבעלים».

### 1. Телефон — нужен один номер
На старом сайте и в Google найдено **пять разных номеров**:

| Номер | Где |
|---|---|
| **052-5634040** | кнопка «התקשרו עכשיו» на главной + WhatsApp-виджет (972525634040) |
| 054-7401246 | плавающая кнопка / баннеры с эвакуатором (из старого шаблона) |
| 1-700-72-5555 | страницы «פחחות רכב», «טיפול בתביעות ביטוח», а также **профиль Google** |
| 03-5182785 | статья «מוסך הסדר של חברות הביטוח?» |
| 03-6812767 | страница «צור קשר» |

В демо везде стоит **052-5634040** (он же WhatsApp) — как временный. Владелец должен назвать один номер; он меняется в одном месте: `src/data/site.js → BUSINESS.phoneDisplay / phoneTel / whatsapp`. Желательно привести к нему и профиль Google.

### 2. Часы работы
Взяты из Google: **вс–чт 08:00–17:00, пт–сб закрыто**. На старом сайте часов нет. Подтвердить (в т.ч. праздники/канун субботы).

### 3. Юридические и финансовые формулировки (повторяют сайт владельца)
- «אתם יכולים לבחור מוסך אחר, בכל חברת ביטוח» — что можно выбрать мастерскую не по «хесдеру».
- «גם אם נפגעתם מנהג אחר (צד ג׳), אנחנו מטפלים בתביעה מול הביטוח, **כולל טיפול משפטי אם צריך**».
- «והעלות שלכם? **אחרי ההחזר שנשיג עבורכם, ההשתתפות העצמית זהה לזו של מוסך הסדר**».
- «מחיר של מוסך הסדר, איכות של מוסך בוטיק».
- Гарантия «**5 שנות אחריות על העבודה**; על החלקים – אחריות מוגבלת לפי תנאי היצרן».
- «**רכב חלופי, חדש או מהשכרה**, כשהרכב בתיקון אחרי תאונה» («מפתח תמורת מפתח»).
- «**איסוף הרכב מהבית** במקרה של תאונה».
Источник — страницы «טיפול בתביעות ביטוח», «פחחות רכב» и главная autoclassltd.com. Тексты переписаны (без опечаток и повторов), смысл не усилен.

### 4. Люди и материалы
- «את מחלקת הפחחות והצבע מנהל **מאיר ממן**» — со страницы «פחחות רכב» (2020). В отзывах Google как руководители чаще упоминаются **שי** и **ניקו**. Подтвердить или убрать имя.
- «צבע של **דופונט** ומוצרי **3M**» — подтвердить, что актуально.
- E-mail **sm@autoclassltd.com** (со страницы «צור קשר») — подтвердить.

### 5. Фото
Используются реальные фото со старого сайта (2020): «до» (вмятина на двери), «в покрасочной камере», «после», работы в мастерской, машина на подъёмнике. Они 700 px и сняты на телефон. Для запуска нужны **свежие фото** мастерской и работ (лучше пары «до/после» с одного ракурса — тогда в слайдере можно сделать классическую шторку). Нейросетевые изображения не использовались. Машина в анимации — собственная SVG-иллюстрация без марки.

### 6. Отзывы и рейтинг
Рейтинг **4.9 и 164 отзыва** — как показано в Google на 23.11.2026. На странице **6 настоящих отзывов**, дословно (с орфографией авторов): כרמל ליברמן, Izik Gur, Nati Yachimovitz, shaniki dot, מני כרמונה (4★), בוריס יגודייב. Владельцу — согласовать выбор. При запуске рейтинг лучше подтягивать автоматически (Google Places API) или обновлять вручную.

### 7. Пример WhatsApp-переписки
Секция «כל הסיפור בצ׳אט אחד» — **иллюстрация** (так и подписано на странице). Если мастерская не присылает такие статусы, текст секции стоит смягчить или превратить в обещание, которое владелец готов выполнять.

### 8. Логотип
Логотип AutoClass векторизован с растрового файла со старого сайта. Если есть оригинальный вектор (AI/SVG/PDF) — заменить `src/components/LogoSymbol.astro`.

### 9. Что не вошло
Страница «קניית טרקטורים משאיות אופנועים לפירוק» (выкуп техники на разборку) не относится к кузовному сервису — не включена. Блок «מכונאות רכב» сохранён одной строкой (страница на старом сайте закрыта защитой от ботов, описание взято с главной).

## Критерии приёмки против старого сайта

| Было на autoclassltd.com | В демо |
|---|---|
| 5 разных телефонов | один номер везде (временный, см. п.1) |
| Блоки повторяются дважды («פחחות וצבע לרכב», «טיפול בתביעות ביטוח») | каждый блок один раз |
| Опечатки: «במיקרה», «מכונאוות», «דיאגונסטיקה», «ריצפה», «של של» | исправлено, тексты переписаны |
| «Please enable JavaScript in your browser to complete this form.» на иврите-сайте | форм нет; вместо них ссылка в WhatsApp; `noscript` на иврите |
| Нет H1 с ключом, слабые title/description | один H1 «מוסך פחחות וצבע בחולון», уникальные title/description, JSON-LD AutoBodyShop |
| Всплывающий WhatsApp-виджет поверх текста | никаких всплывающих окон и плавающих кнопок |
| Сырые ссылки и шаблонные иконки | нет |
