Общие выводы, которые легли в страницу:
1. Возраст бизнеса — главный аргумент доверия. **1960** старше всех найденных конкурентов → в eyebrow hero и в истории.
2. Главный путь в Израиле — **WhatsApp с фото** (у Элада — зелёная кнопка; у Sheen — загрузка фото). У нас — одна кнопка с готовым текстом.

## 2. Идея

**«От удара до ключей» — сайт, который сам ремонтирует машину.**

Клиент приходит после аварии: стресс, вопросы «что делать?», «останусь ли без машины?», «как с ними связаться?». Страница отвечает на это **действием, а не текстом**:

- Даже заголовок H1 при загрузке «помят»: буквы перекошены и выпрямляются одна за другой (справа налево — в направлении чтения), последняя «вмятина» щёлкает с лаймовой вспышкой. Метафора ремонта начинается ещё до скролла.
- На скролле та же самая машина проходит все 4 этапа и превращается из помятой серой в свежеокрашенную — в фирменный **лаймовый** цвет логотипа Auto Class (на старом логотипе как раз лаймовая машина).
- Главное действие — одна кнопка: «שלחו לנו תמונה של הנזק בוואטסאפ» с готовым текстом сообщения. Она есть в шапке, hero, страховом блоке, чате и контактах; телефон — вторичный путь.

Почему это сильнее стартовой идеи из брифа: сохранены все пять вау-моментов, но они связаны **одной метафорой** (вмятина → ремонт → блеск), а не разложены по странице как отдельные эффекты. Это то, что жюри называет Creativity, и одновременно Content: каждая анимация объясняет реальный этап работы мастерской.

## 3. Палитра

Взята из логотипа autoclassltd.com (лаймовая машина и надпись AutoClass), очищена и доведена до AA-контраста.

| Токен | Цвет | Роль |
|---|---|---|
| `--ink` | `#121310` | тёмный «гараж ночью», основной фон |
| `--ink-2` | `#1a1c17` | карточки на тёмном |
| `--paper` | `#eeede6` | светлые секции (страховая, услуги, отзывы) — тёплая «малярная бумага» |
| `--lime` | `#b9ca13` | фирменный лайм Auto Class: CTA, акценты, итоговая краска машины |
| `--lime-hi` | `#d6e12d` | блик/hover |
| `--lime-ink` | `#3d4404` | лаймовая типографика на светлом (AA) |
| `--signal` | `#ff5b38` | только метки повреждений на этапе осмотра и пометки «на проверку» в режиме комментариев |

Ритм тёмное/светлое: драматичные сцены (hero, процесс, гарантия, чат, до/после, контакты) — тёмные; информационные (страховая, услуги, отзывы) — светлые, чтобы читать спокойно.

Контраст: лайм на `#121310` ≈ 10.9:1, текст `#a3a79c` на `#121310` ≈ 7:1, тёмный текст на лайме ≈ 10.9:1.

## 4. Типографика

- **Noto Sans Hebrew (variable, оси wght 100–900 и wdth 62.5–100)** — единственная рабочая гарнитура. Заголовки — 860/68% ширины: узкий тяжёлый гротеск даёт «автомобильную», плакатную интонацию (у иврита нет прописных, поэтому плотность создаём шириной и весом). Текст — 400/100%.
- **Frank Ruhl Libre** — только для коротких «человеческих» фраз (слоган «הכי טוב לרכב שלך», «מחיר של מוסך הסדר, איכות של מוסך בוטיק»): классическая еврейская антиква как голос семейной мастерской с 1960 года.
- Self-host, сабсет: иврит 16 КБ, латиница 25 КБ, Frank Ruhl 17 КБ (woff2). Предзагружается только ивритский файл; metric-matched fallback держит CLS = 0.

## 5. Фирменные анимационные моменты

1. **Вход: «помятый» заголовок + машина въезжает.** H1 «מוסך פחחות וצבע בחולון» собран из букв со случайными (детерминированными) смещениями/поворотами/сжатием; они выпрямляются с пружиной справа налево, последняя буква-«вмятина» щёлкает с лаймовой вспышкой. Помятая SVG-машина въезжает справа (сзади), колёса поворачиваются ровно на угол, соответствующий пройденному пути, кузов «приседает» при остановке. Всё на чистом CSS — работает до загрузки JS, LCP не задерживается. CTA виден сразу.
2. **Pinned-восстановление «מהפגיעה ועד המפתחות».** Sticky-сцена на 520vh, один GSAP-таймлайн, скраб скроллом (на десктопе через Lenis):
   - 01 קבלה ובדיקה — лаймовый луч сканирует машину справа налево, повреждения загораются метками с подписями;
   - 02 תיאום מול הביטוח — машина превращается в чертёж оценщика (контур рисуется, размерные линии), выезжает «תיק תביעה» и галочки ставятся по очереди;
   - 03 פחחות וצבע — вмятины вытягиваются (морфинг путей кузова, без MorphSVG), складки выпрямляются, царапины стираются, грунт со шпаклёвкой, затем **волна лака** проходит справа налево и по кузову пробегает блик;
   - 04 מסירת הרכב — включаются фары, машина чуть трогается вперёд, появляются «המפתחות שלכם».
   Направление всех движений — справа налево (RTL = «вперёд»); машина смотрит влево, т.е. едет в направлении чтения.
3. **Блик лака за курсором / наклоном.** Световая полоса на кузове следует за курсором (hero и финал сцены), на телефоне — за пальцем и наклоном устройства (DeviceOrientation там, где не нужен системный запрос; на iOS — только касание, никаких всплывающих окон). Свет в hero тоже идёт за курсором.
4. **«Лента ремонта» по реальным фото.** Фото «до», «в покрасочной камере» и «после» с сайта владельца сняты с разных ракурсов, поэтому классическая шторка дала бы кривое совмещение. Вместо неё — перетягиваемая шкала: «до» приближается, «камера» проявляется, «после» отъезжает как камера, показывая всю машину. Работает мышью, пальцем и клавиатурой (role="slider", стрелки в RTL-логике, Home/End), есть кнопки 01/02/03.
5. **Живой WhatsApp-чат.** Телефон закреплён на экране, сообщения «приходят» по мере скролла; перед каждым ответом мастерской — «מקליד/ה…» в шапке и пузырь с точками. Внутри — реальные фото работ. При скролле назад сообщения уходят обратно. Подписано: «המחשה בלבד».
6. (дополнительно) **Микроанимации гарантий**: кольцо «5» заполняется и считает до 5, два ключа меняются местами («מפתח תמורת מפתח»), печать «מקורי» падает со стуком, точка-машина едет от дома до мастерской. Пункты меню и кнопки — «лаковый» блик при наведении. Кастомный курсор (точка + кольцо с подписью «גררו»/«וואטסאפ») — только при `pointer: fine`.

Правила: `prefers-reduced-motion` → без движения, сцены превращаются в обычные списки с уже восстановленной машиной, чат показан целиком. Мобильная версия — тот же сюжет, короче и без Lenis (нативный скролл). Никакого автоплей-видео и WebGL: SVG + CSS + GSAP.

## 7. Технические решения

- **Astro 7 (static)**, весь CSS инлайнится (критический CSS = весь CSS, ~25 КБ brotli вместе с HTML).
- JS: основной модуль крошечный (шапка, reveal, слайдер, карта). GSAP + ScrollTrigger + Lenis подгружаются **после `load` и idle**, инициализация разбита на задачи → TBT ≈ 150 мс на мобильном.
- Секции ниже чата — `content-visibility: auto` (первый рендер в 3 раза дешевле).
- Изображения: AVIF/WebP + srcset через `astro:assets`, все lazy; в hero изображений нет (LCP — текст).
- Логотип — векторизован (potrace) с лаймового растрового логотипа клиента, лежит один раз как `<symbol>`.
- Машина — собственная обобщённая SVG-иллюстрация без марки и модели; два состояния путей с одинаковой структурой команд, интерполяция ~20 строк кода (без платных/тяжёлых плагинов).
- Комментарии «как в Figma» — отдельный скрипт, грузится только по ссылке ревью (`?review=…`), см. `docs/COMMENTS.md`.
